# EudaiLabs — Foundation

This repository contains the documents that define Eudai Labs: what we are, what we stand for, and how we operate. They are the reference point for decisions about clients, projects, and the company itself.

The [manifesto](manifesto.md) explains why the company exists and how we approach our work. The [company values](company-values.md) define the behaviors we expect from ourselves and the people who join us. The [operating principles](operating-principles.md) set the standards for how we build and deliver. The [strategic direction](strategic-direction.md) defines our mission and position. The [ethics framework](ethics-framework.md) is the classification system we apply before taking on any project.

These documents are not marketing material. They are the actual criteria we use when deciding what to build, who to work with, and how to work. We make them public because we think that kind of transparency is part of doing serious work.

If something here does not match how we actually operate, that is a failure to correct — not a reason to rewrite the document.
